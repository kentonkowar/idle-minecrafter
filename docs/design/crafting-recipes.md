# Crafting Recipes: Idle Minecrafter Components

2026-09-30 · smithy

## Nether Furnace

A specialized furnace for refining nether stars into refined nether stars. Runs on end crystals.

**Recipe:**

```
[Nether Brick] [Eye of Ender] [Nether Brick]
[Obsidian] [Dragon's Breath] [Obsidian]
[Nether Brick] [Obsidian] [Nether Brick] 
```

Result: **Nether Furnace** (1)

---

## Refined Nether Star

Created by smelting a Nether Star in a Nether Furnace using 8 End Crystals as fuel.

**Nether Furnace Recipe:**

- Input: Nether Star
- Fuel: End Crystal (8 per nether star)
- Output: **Refined Nether Star** (1)
The end crystals each have a burn time of 38400 ticks. They can only be used in nether furnaces and 8 of them are required to complete a refined nether star

---

## Collapsed Nether Star

The highest-tier storage material. Made from 9 Refined Nether Stars in a 9×9 crafting grid.

**Recipe:**

```
[Refined Nether Star] [Refined Nether Star] [Refined Nether Star]
[Refined Nether Star] [Refined Nether Star] [Refined Nether Star]
[Refined Nether Star] [Refined Nether Star] [Refined Nether Star]
```

Result: **Collapsed Nether Star** (1)

## Idle Controller

The anchor block for a setup. Houses the chunk selection UI and confirmation screen.

**Recipe:**

```
[Cobble Stone] [Furnace] [Cobble Stone]
[Stonecutter] [Crafting Table] [Grindstone]
[Cobble Stone] [Hopper] [Cobble Stone]
```

Result: **Idle Controller** (1)

---

## Surveyor

A tool for selecting chunks and linking storage to the controller in the world.

**Recipe:**
make this recipe vertical but can be in any of the three slots.
The glass pane can be clear or any color.
```
[empty] [Glass Pane] [empty]
[empty] [Idle Controller] [empty]
[empty] [Stick] [empty]
```

Result: **Surveyor** (1)

## Storage Tier Capacities

Stack count capacity for each tier (number of items that can be stored).

| Tier                  | Minimum Capacity | Maximum Capacity | Upgrade Cost           | Upgrade Steps | Notes                                                                       |
| --------------------- | ---------------- | ---------------- | ---------------------- | ------------- | --------------------------------------------------------------------------- |
| Wood                  | 27 stacks        | 45 stacks        | Chest                  | 2             | Base tier                                                                   |
| Copper                | 54 stacks        | 81 stacks        | Copper Blocks          | 3             | 9 stacks per upgrade                                                        |
| Iron                  | 108 stacks       | 189 stacks       | Iron ingots            | 9             | 9 stacks per upgrade                                                        |
| Gold                  | 216 stacks       | 297 stacks       | Gold ingots            | 3             | 27 stacks per upgrade                                                       |
| Amethyst              | 324 stacks       | 405 stacks       | Amethyst Shards        | 9             | 9 stacks per upgrade                                                        |
| Diamond               | 432 stacks       | 837 stacks       | Diamonds               | 8             | Upgrade as close to an even 9 stacks at once and save extra stacks for last |
| Amethyst Cluster      | 864 stacks       | 1296 stacks      | Amethyst Clusters      | 16            |                                                                             |
| Netherite             | 1728 stacks      | 3456 stacks      | Netherite Ingots       | 2             |                                                                             |
| Collapsed Nether Star | 6912 stacks      | 55296 stacks     | Collapsed Nether Stars | 3             | upgrade doubles storage amount instead of linearly                          |

### Capacity Notes

- **Minimum capacity** is reached when the block is first created or upgraded.
- **Maximum capacity** is reached by applying additional materials of the same tier in the controller's storage upgrade screen.
- Each upgrade step within a tier increases capacity up to the maximum.
- Offline output stops when the storage reaches maximum capacity.
- The Catch-up Calculation doc will specify how overflow is handled (sent to other storage, lost, or queued).
